# Sales Intelligence | SQL Analytics
Streamlit + SQLite sales dashboard. Ships with a seeded **synthetic** demo dataset; upload a Superstore-style CSV in the sidebar to use real data.

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows (macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt
streamlit run app.py
```
Deploy: push to GitHub, then on share.streamlit.io choose the repo and `app.py`.
